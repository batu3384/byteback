### NF-001 | Yüksek | Metadata checkpoint carve resume bozulması

**Kanıt:** Metadata fazında `updateScanCheckpoint(scanId, false, current)` çağrılıyor; `current` genel ilerleme (metaBudget içinde mapped sector), carve resume offset değil.

```549:554:native/src/bridge/bridge_scan.cpp
            if (phasePtr && std::strcmp(phasePtr, "metadata") == 0 &&
                ...
                engine->getMetadataStore().updateScanCheckpoint(checkpointScanId, false, current);
```

Resume'da `target.carveResumeSector = st.carveResumeSector` (`bridge_scan.cpp:401`). `runCarveScan` bu değeri carve range sayacıyla karşılaştırır (`scan_coordinator.cpp:340-353`). Metadata ilerlemesi carve toplamından büyükse **tüm carve atlanır**.

**Etki:** Metadata ortasında pause → resume → dosya listesi var ama carve hiç çalışmaz; kullanıcı deep scan tamamlandı sanabilir.

**Yön:** Metadata checkpoint'te `carveResumeSector=0` tut; yalnız carve fazında `onCheckpoint(true, current)` güncelle.
